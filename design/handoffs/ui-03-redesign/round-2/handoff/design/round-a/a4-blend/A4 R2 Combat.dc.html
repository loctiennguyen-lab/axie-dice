02-net-retry · NEW state · top centre, does not lock input
Reconnecting… you can keep planning. Moves send when we're back.
Retry now
run_session: state "reconnecting" (8 s timeout, up to 3 re-sends). Picking dice and targets still works; actions that need a server roll (Reroll, End turn, Continue) show their spinner until answered. After 30 s with no answer the state becomes "offline" and this notice reads "Can't reach the server. Your run is saved." with Retry.

run_session closes with code "expired" (WS 1008) or "version" (4001). Version variant: title "Update needed", one button "Back to menu". Both lock the stage. Esc: nothing. Another account, or a run the server no longer holds: "Your unfinished run is no longer open on the server, so it can't be continued." with only Back to menu.
