TYPE SCALE · FONT IS THE SINGLE BIGGEST WIN

DangoTheme.FONT is null, so every label in the game renders in Godot's built-in fallback. That single fact is most of "font mặc định trông rẻ". Ship the two files under assets/fonts/, build one Theme resource, assign it on the root Control of every scene — then no screen needs a per-label font override ever again.
✔ FONT DEVIATION APPROVED · 20 SEP 2026 · BUILD ON BALOO 2
The mockups set Baloo 2 on all display type, not Work Sans. Work Sans is what Dango specifies and what DangoTheme.gd's own header already flags as missing — so this deviation is recorded the same way that file records its own, rather than left to drift.

Why: Work Sans and Barlow Condensed are neutral grotesks. On a screen of black-outlined flat-tone cards they produce exactly the "sang nhưng vô hồn" read the first pass was rejected for — the letterforms belong to a dashboard, the artwork belongs to Lunacia. Baloo 2 is a rounded heavy face whose weight and terminals match the 9-unit black outline the kit draws with, which is what makes type and art look authored by the same hand.

Scope of the deviation: display only. Work Sans keeps every paragraph — log lines, passive text, relic and event descriptions — so Dango's reading face is intact. Approved as written — build on Baloo 2. The Work Sans 700 fallback is withdrawn and is not to be implemented; it stays recorded here only as the rejected alternative.

TWO RULES THAT DECIDE THE NUMBERS
Damage counts what actually lands: after Shield absorption, after Weaken, clamped to the target's remaining HP so an overkill of 40 into a 6 HP enemy scores 6. Poison and Thorns count toward damage_dealt but never toward biggest_hit — biggest hit is one die resolution against one target, which is the number a player can recognise. Both rules live in the accumulator, not in the callers.

The label on the first tile is whatever the Godot run structure calls it. The mockup reads WAVES CLEARED 12 / 12 because that is what the JS build reported; if a Godot run is tiers of nodes rather than a fixed wave count, the tile becomes NODES CLEARED against the run length and the accumulator field is renamed with it.
