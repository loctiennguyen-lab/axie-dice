**Định nghĩa "xong" cho mọi việc từ nay:**
1. Code + test (không gọi mạng)
2. Agent khác review: MERGE
3. Merge commit đã review → `git diff --diff-filter=U` sạch → suite cây chính xanh, không SKIP
4. Việc chạm online / server / đăng nhập: **live smoke PASS trên production**
5. Việc chạm UI: chụp ảnh ở 2 cỡ cửa sổ, có người xem ảnh
6. Push. Deploy Worker: hỏi Liam trước, trừ khi Liam đã bảo chạy
