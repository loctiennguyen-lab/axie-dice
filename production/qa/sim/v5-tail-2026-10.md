## 5. t_desktop_signin
Root cause: on macOS a REFUSED loopback connect shows up in Godot's StreamPeerTCP as CONNECTING, CONNECTED (one frame), NONE. The test's _port_open() took the first CONNECTED as an open port, so every "port closed/refuses" assert failed. Not a fixed port (DesktopAuth already uses a random one). Fix: _port_open counts CONNECTED only if still connected 6 frames later. Asserts unchanged.
