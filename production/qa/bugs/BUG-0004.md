# BUG-0004 — Sau reset R3: client hiện số dư cũ và kẹt "Continue run"

- Mức: S2 (thông tin tiền sai + ngõ cụt; server đúng, không đúc được tiền vì mọi giao dịch qua server).
- Thấy ở: production R3, tài khoản Liam (web), ngay sau reset 27/10.
- Hiện tượng: `GET /api/econ` trả shard 500 / stone 0 / ticket 3 / reset_id 20261027043117, nhưng Land hiện 560 Shard / 500 Stone. Nút "Continue run" → toast "That run could not be loaded", nút vẫn là "Continue run".
- Nguyên nhân: `MetaState.apply_server_econ` (godot/autoload/MetaState.gd ~290) hoãn TOÀN BỘ (cả wipe lẫn số dư) khi `RunState.phase != MENU`; máy còn save run cũ (bản trước reset, server đã xoá run) nên phase khác MENU → không bao giờ áp. Continue lỗi nhưng save run không bị xoá.
